## Reproduce

Use Python 3.11 or newer for the pinned demo dependencies. The engine itself
uses only the Python standard library and follows the template API.

```bash
python -m pip install -r requirements.txt
python -m pytest
python -m notebook demo.ipynb
```

In Jupyter, restart the kernel and run all cells. Figures and result files are
regenerated. Training uses 48 rows; the 24 test rows are evaluated separately.
Only `matplotlib` and `numpy` are used for visualization. No PyTorch or external
autograd library is used. Matplotlib may choose a different default font on
another system; numerical results should agree up to floating-point rounding.

To compile the report after running the notebook:

```bash
cd report
pdflatex main.tex
pdflatex main.tex
```

Tectonic can also compile `main.tex`. The figures are referenced from `../figures/`.
