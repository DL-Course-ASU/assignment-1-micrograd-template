1. Verify the engine before training¶

For each scalar operation, the local backward closure adds an upstream derivative times its local partial derivative. A visited set makes each graph node execute once, while the closure still adds both operand contributions when they refer to the same Value. Central finite differences independently check 60 partials.

2. Generate noisy two-moons data and reserve the test set¶

The first arc is (cos(t), sin(t)); the second is (1-cos(t), 0.5-sin(t)), with independent Gaussian noise of standard deviation 0.12. Each class has 120 samples. A seeded permutation reserves 40 from each class for testing and uses 80 from each class for training. No normalization is learned from the test samples.

3. Define the model and objective¶

The network has widths 2 -> 8 -> 8 -> 1, tanh at every neuron, and 105 trainable parameters. Labels are -1 and +1; score zero is the decision threshold. The objective is mean squared error plus an L2 penalty on weights:

$$L(\theta)=\frac{1}{N}\sum_i(f_\theta(x_i)-y_i)^2 +\frac{10^{-4}}{|W|}\sum_{w\in W}w^2.$$

Full-batch gradient descent uses $\eta_e=0.12(1-0.75e/300)$ for 300 updates. Every update builds a fresh graph, clears parameter gradients, backpropagates once, and updates parameters after differentiation. Metrics are measured at each recorded parameter state, including state 0.

In [5]:
model = MLP(2, [8,8,1])
params = model.parameters()
weights = [w for layer in model.layers for neuron in layer.neurons for w in neuron.w]
assert len(params) == 105
L2 = 1e-4
EPOCHS = 300
def scalar_score(row):
    # Graph-free scalar inference for logging and dense plotting only.
    current = row
    for layer in model.layers:
        current = [math.tanh(sum(w.data*x for w,x in zip(n.w,current))+n.b.data)
                   for n in layer.neurons]
    return current[0]
def metrics(rows, labels):
    scores = [scalar_score(row) for row in rows]
    mse = sum((score-label)**2 for score,label in zip(scores,labels))/len(labels)
    accuracy = sum((score>=0)==(label>0) for score,label in zip(scores,labels))/len(labels)
    return mse, accuracy
def record(epoch):
    train_mse, train_acc = metrics(X_train,y_train)
    test_mse, test_acc = metrics(X_test,y_test)
    reg = L2*sum(w.data**2 for w in weights)/len(weights)
    return dict(epoch=epoch,objective=train_mse+reg,train_mse=train_mse,
                test_mse=test_mse,train_accuracy=train_acc,test_accuracy=test_acc)
print('Parameters:', len(params), '| regularized weights:', len(weights))

history = [record(0)]
start = time.perf_counter()
for epoch in range(EPOCHS):
    predictions = [model(row) for row in X_train]
    data_loss = sum((prediction-label)**2 for prediction,label in zip(predictions,y_train))/len(y_train)
    penalty = (L2/len(weights))*sum(w*w for w in weights)
    loss = data_loss+penalty
    assert math.isfinite(loss.data)
    model.zero_grad()
    loss.backward()
    rate = .12*(1-.75*epoch/EPOCHS)
    for p in params:
        p.data -= rate*p.grad
    history.append(record(epoch+1))
    if (epoch+1)%50 == 0:
        last = history[-1]
        print(f"Epoch {epoch+1:3d} | objective {last['objective']:.5f} | "
              f"train {last['train_accuracy']:.1%} | test {last['test_accuracy']:.1%}")
    del predictions, data_loss, penalty, loss
    if epoch%10 == 0:
        gc.collect()
elapsed = time.perf_counter()-start
for row in X_train+X_test:
    assert math.isclose(model(row).data,scalar_score(row),rel_tol=1e-12,abs_tol=1e-12)
summary = dict(seed=SEED,epochs=EPOCHS,parameters=len(params),train_samples=len(X_train),
    test_samples=len(X_test),initial=history[0],final=history[-1],training_seconds=elapsed,
    verification=verification)

5. Interpretation and limits¶

The curved zero contour shows that a composition of scalar neurons can learn a nonlinear classifier. A held-out split gives a more useful check than training accuracy alone, although this is one small synthetic dataset and one seed. The implementation prioritizes readable chain-rule mechanics: it has no tensors, GPU execution, batching primitive, retained-graph management, or automatic gradient reset. Recursive DFS is limited by Python's recursion depth on very deep chains. exp follows Python overflow behavior and real powers require a valid real domain. Dense figures use a graph-free scalar evaluation of the same learned weights, checked against MLP.__call__ on every dataset sample.
