\section{Chain rule and primitive arithmetic}
\textbf{Specification coverage.} The supplied three-page assignment requires
\code{Value}, arithmetic and activation derivatives, DFS topological sorting,
\code{Neuron}/\code{Layer}/\code{MLP}, a demo notebook, and a LaTeX report.
There are no additional standalone conceptual questions in the PDF or template
README. The explanations below answer the conceptual issues implicit in those
requirements, including both TA warnings.

\subsection{Reverse-mode differentiation on a DAG}
Let $L$ be a scalar output, and let $C(u)$ contain the immediate consumers of
$u$ in the forward computational graph. These consumers are sometimes called
the parents of $u$ when tracing backward. The multivariable chain rule is
\begin{equation}
 \frac{\partial L}{\partial u} =
 \sum_{v\in C(u)}\frac{\partial L}{\partial v}
                         \frac{\partial v}{\partial u}.
 \label{eq:dag}
\end{equation}
Each summand describes one path by which changing $u$ changes $L$.
Repeated operand occurrences contribute separately even if the graph stores a
single shared input node. The terminal seed is $\partial L/\partial L=1$.
Reverse mode is useful here because one backward sweep yields the derivative
of a scalar loss with respect to every network parameter.

\subsection{Addition}
For $z=x+y$, holding $y$ fixed gives
$\lim_{h\to0}[(x+h+y)-(x+y)]/h=1$. By symmetry,
\[
 \frac{\partial z}{\partial x}=1,\qquad
 \frac{\partial z}{\partial y}=1.
\]
If $\bar z=\partial L/\partial z$, add $\bar z$ to both operand gradients.
For $z=x+x$, the same node receives two increments, giving $2\bar z$.

\subsection{Multiplication}
For $z=xy$, the difference quotient with respect to $x$ is
$[(x+h)y-xy]/h=y$; interchanging $x$ and $y$ yields
\[
 \frac{\partial z}{\partial x}=y,\qquad
 \frac{\partial z}{\partial y}=x.
\]
The closure therefore adds $y\bar z$ to $x$ and $x\bar z$ to $y$.
For $z=x^2$ implemented as $x*x$, both increments reach $x$ and sum to
$2x\bar z$.

\subsection{Constant powers and derived operations}
For a fixed real $k$, $z=x^k$ has local derivative $kx^{k-1}$ on its
differentiable real domain. For positive integer $k$, this follows by expanding
$(x+h)^k$ and retaining the coefficient of $h$. Negative and fractional powers
follow the usual extension on valid real domains.

Negation is multiplication by $-1$; subtraction is addition of a negation.
Division is $x/y=x\,y^{-1}$, so
$\partial(x/y)/\partial x=1/y$ and
$\partial(x/y)/\partial y=-x/y^2$. Reverse operators allow expressions such
as $2-x$ and $2/x$ to construct the same differentiable primitives.

\section{Activations and numerical conventions}
\subsection{Exponential}
For $z=e^x$, using $\lim_{h\to0}(e^h-1)/h=1$ gives
\[
 \frac{dz}{dx}=\lim_{h\to0}e^x\frac{e^h-1}{h}=e^x=z.
\]
The backward closure reuses the forward result: $\bar x\mathrel{+}=z\bar z$.
The implementation calls \code{math.exp}; sufficiently large positive inputs
raise Python's \code{OverflowError} instead of silently fabricating a value.

\subsection{Hyperbolic tangent}
Writing $q=e^{2x}$ gives $z=(q-1)/(q+1)$ and $dq/dx=2q$. The quotient rule
yields
\begin{align*}
 \frac{dz}{dx}
 &=\frac{2q(q+1)-(q-1)2q}{(q+1)^2}
   =\frac{4q}{(q+1)^2},\\
 1-z^2
 &=\frac{(q+1)^2-(q-1)^2}{(q+1)^2}
   =\frac{4q}{(q+1)^2}.
\end{align*}
Thus $dz/dx=1-z^2$ and $\bar x\mathrel{+}=(1-z^2)\bar z$.
The code uses \code{math.tanh(x)} for the forward pass, avoiding the
overflow-prone explicit exponential formula. Inputs $\pm1000$ are checked:
the outputs saturate at $\pm1$ and their floating-point derivatives are zero.

\subsection{Optional ReLU}
For $z=\max(0,x)$ the derivative is 1 for $x>0$ and 0 for $x<0$.
At the nondifferentiable point $x=0$, the implementation chooses subgradient
zero. ReLU is included as a supplemental operation; the template networks
continue to use tanh at every layer.

\subsection{Explicit domain and state decisions}
\begin{itemize}
\item Values wrap Python \code{int} or \code{float} data. Strings, lists, and
other unsupported data raise \code{TypeError}.
\item Exponents are fixed \code{int}/\code{float} scalars, matching the
template assertion contract. Differentiable exponents are outside scope.
\item Division by zero raises \code{ZeroDivisionError}. Powers producing
complex results are rejected because this engine represents real scalars.
\item $x^0$ is treated as a constant with derivative zero, including Python's
forward convention $0^0=1$. A fractional power at zero may have no finite
derivative; the implementation does not promise differentiation there.
\item Data must remain unchanged between graph construction and backward.
Training updates parameters only after the entire backward sweep.
\end{itemize}
The engine performs ordinary Python floating-point arithmetic. It does not
provide symbolic simplification, automatic precision selection, or special
handling for every nonfinite input.

\section{Value architecture and gradient lifecycle}
\begin{center}
\begin{tabular}{p{.19\linewidth}p{.72\linewidth}}
\toprule
Field & Purpose\\\midrule
\code{data} & Scalar forward value.\\
\code{grad} & Accumulated derivative of the chosen scalar output. Initially 0.0.\\
\code{\_prev} & Set of input-node references; keeps dependencies for traversal.\\
\code{\_backward} & Closure implementing one operation's local chain rule.\\
\code{\_op}, \code{label} & Operation and human-readable label for inspection.\\
\bottomrule
\end{tabular}
\end{center}
Each overloaded operator wraps scalar constants, computes a forward scalar,
creates a new output node, and installs a closure referring to its operands and
output. Constants also receive gradients in this simple design; only the list
returned by \code{parameters()} is updated during optimization.

\subsection{Why a set does not erase repeated-operand derivatives}
For $c=a+a$, \code{c.\_prev} contains $a$ once. This is sufficient for
traversal. The addition closure retains both operand roles and executes two
increments, even though \code{self} and \code{other} reference the same object.
Graph-node identity and operand multiplicity serve different purposes.

\begin{lstlisting}[language=Python]
def _backward():
    self.grad += out.grad
    other.grad += out.grad
\end{lstlisting}
Replacing either increment with assignment loses contributions from other
paths. Equation~\ref{eq:dag} requires a sum; \code{+=} directly implements it.
Only the root seed uses assignment: \code{self.grad = 1.0}.

\subsection{Fresh graphs and deliberate reset semantics}
\code{reset\_grad()} clears one Value. \code{Module.zero\_grad()} clears the
trainable leaves exposed by that module. Neither automatically resets every
intermediate in an old graph. The demo constructs a fresh graph for every loss,
zeros parameter gradients, runs backward, and then changes parameter data.

Calling backward twice on the same graph without clearing intermediates can
repropagate stale accumulated gradients. To differentiate that same graph
again, reset every node returned by \code{\_get\_topo()} first. The tests
verify both a complete graph reset and deliberate accumulation across fresh
graphs sharing a leaf. This behavior is documented in the API rather than
silently clearing user gradients inside backward.

\subsection{Costs and limits}
DFS traversal and reverse execution each take $O(V+E)$ work for a graph with
$V$ nodes and $E$ dependency edges, plus $O(V)$ traversal storage. Scalar
networks create many Python objects, so this implementation is educational
rather than a high-throughput tensor framework. Recursive DFS is limited by
Python's recursion depth on very deep chains. Set iteration may choose different
valid sibling orders; all still place each dependency before its consumer.

\section{Topological sorting and the two traps}
\begin{lstlisting}[language=Python]
def _get_topo(self):
    topo, visited = [], set()
    def build_topo(node):
        if node not in visited:
            visited.add(node)
            for child in node._prev:
                build_topo(child)
            topo.append(node)  # outside the child loop
    build_topo(self)
    return topo
\end{lstlisting}
\code{backward()} seeds the root with 1.0, then runs the closures in reverse
topological order.
\subsection{The Post-Order Trap}
Forward topological order places an operand before each consumer. Appending
only after visiting \emph{all} inputs establishes that invariant inductively:
leaves are appended immediately, and every internal node is appended after
its already-ordered dependencies. Reversing the list places every consumer
before its operands, so all upstream contributions arrive before a node
propagates them further. Appending inside the child loop can insert a node
prematurely or repeatedly; appending only inside that loop also omits leaves.

\subsection{The Diamond Graph Trap}
Consider $c=a+a$ and $d=ca=2a^2$. At $a=3$, $c=6$ and $d=18$.
Backpropagation first adds $a=3$ to $c$'s gradient and $c=6$ directly to
$a$'s gradient. Then $c$ contributes 3 twice to $a$, yielding
$\bar a=6+3+3=12$. The graph below shows repeated operand edges explicitly.
\fig{computational_graph.pdf}{.88}{One shared Value, two operand roles, three total gradient contributions.}
The visited set ensures each unique node appears once, preventing redundant
execution on shared subgraphs. A genuine DAG cannot loop infinitely merely
because a node is reused; revisiting causes duplicate work, potentially
exponential traversal, and incorrect propagation if closures run repeatedly.
The assignment warning motivates deduplication, but cycles are not created
by ordinary forward operator construction.

\section{Neural-network API and training design}
\subsection{Composition and parameter ownership}
A shared \code{Module} supplies \code{zero\_grad()} through
\code{parameters()}. A \code{Neuron(nin)} owns \code{nin} weights and one
bias, all initialized independently from $\mathcal U(-1,1)$. Its output is
\[
 a=\tanh\left(\sum_{j=1}^{n_{in}}w_jx_j+b\right).
\]
A \code{Layer(nin,nout)} evaluates independent neurons on the same input.
It returns a list for multiple outputs and a scalar Value for a single output,
as required by the template. \code{MLP} chains these layers. When an
intermediate layer has width one, it wraps that scalar in a one-element list
before the next layer. This avoids a hidden shape failure in bottleneck
architectures such as $2\to1\to3\to1$.

Parameter collection flattens neuron, layer, and model ownership in a stable
order, without cloning the Value objects. Gradients and updates therefore
refer to the same underlying weights. Positive dimensions and exact input
widths are validated so \code{zip} cannot silently discard missing inputs.

\subsection{Reproducible experiment}
The executed notebook creates two interleaving semicircles with Gaussian
coordinate noise $\sigma=0.12$. There are 240 points and two features. A
seeded, class-balanced split uses 160 for training and 80 for testing. Both
the Python parameter RNG and NumPy data RNG use seed 42. No normalization
statistics, gradients, early stopping decisions, or parameter updates use the
test set.

The network $2\to8\to8\to1$ has
$(2+1)8+(8+1)8+(8+1)1=105$ trainable scalars, of which 88 are weights.
Every layer uses tanh to preserve the template contract; class labels are
$-1$ and $+1$, and scores are thresholded at zero. The loss is
\[
 L=\frac1{160}\sum_{i=1}^{160}(f_\theta(x_i)-y_i)^2
      +\frac{10^{-4}}{88}\sum_{w\in W}w^2.
\]
Biases are excluded from regularization. The gradient of the data term with
respect to score $s_i$ is $2(s_i-y_i)/160$; the weight penalty contributes
$2\cdot10^{-4}w/88$ to each regularized weight.

\subsection{Optimization lifecycle}
For updates $e=0,\ldots,299$, use
$\eta_e=0.12(1-0.75e/300)$. Each iteration computes predictions and scalar
loss, calls \code{model.zero\_grad()}, runs \code{loss.backward()}, and applies
$\theta\leftarrow\theta-\eta_e\nabla L$. A fresh forward graph is then
constructed. Metrics are recorded at parameter states 0 through 300, so the
last curve point and saved weights describe the same model.

Logging and dense contours evaluate the learned scalar equations without
allocating autodiff graphs. This inference path is checked against the actual
MLP on all 240 dataset points to $10^{-12}$ tolerance. All optimization
gradients still use Value and its chain-rule closures.

An independent script checks
\[
 f(x,y)=\tanh(xy+x^3)+\frac{e^{x-y}}{y^2+2}+\frac{2}{x^2+1}

\[

very small $h$ amplifies floating-point cancellation. These checks deliberately

\section{Learned decision geometry}
\fig{decision_boundary.pdf}{.98}{Circles are training points; triangles are reserved test points. The dark contour is score zero.}
The score field is a composition of tanh activations and learned affine maps.
Its curved zero contour separates the interlocking arcs, which a single
straight line cannot fully describe. The color scale conveys output score,
not a calibrated probability. Outside the sampled arcs the contour is an
extrapolation; an attractive plot alone does not establish reliability there.

\subsection{Why nonlinear layers matter}
Without activations, composing affine maps produces another affine map,
$W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$. Hidden depth by itself
would then fail to add nonlinear decision geometry. Tanh breaks this collapse
and supplies smooth derivatives, allowing the scalar chain rule to train
multiple layers together. Saturation can make those derivatives small, which
is one reason to examine both loss and accuracy during learning.

and verification details are also exported in readable JSON. Every plotted
