\section{Objective and Implementation Overview}
This assignment~\cite{assignment} implements a scalar automatic differentiation engine and a small
neural network API using Python. The engine records arithmetic operations as a
computational graph and applies reverse-mode differentiation to compute the
derivative of a scalar output with respect to its inputs. A multilayer perceptron
(MLP) is then built entirely from these differentiable scalar operations.

The implementation follows the supplied assignment template~\cite{template}.
The engine and training calculations use the Python standard library; PyTorch
is not used for differentiation or optimization.

\subsection{Structure of the implementation}

\subsection{The \texttt{Value} representation}
Each \texttt{Value} stores a numerical value in \texttt{data} and an accumulated
gradient in \texttt{grad}. If the final scalar output is $L$, the gradient of an
intermediate node $v$ represents $\partial L/\partial v$ after backpropagation.

\begin{tabularx}{\textwidth}{@{}lX@{}}
\toprule
\textbf{Attribute} & \textbf{Meaning} \\
\midrule
\texttt{data} & The result of the forward calculation at this node. \\
\texttt{grad} & The accumulated derivative, initialized to zero. \\
\texttt{\_prev} & A set of input nodes used to produce this node. \\
\texttt{\_backward} & A local function that propagates gradients to the inputs. \\
\texttt{\_op}, \texttt{label} & Operation metadata and an optional readable name. \\
\bottomrule
\end{tabularx}

\subsection{Recording the forward graph}
Operator overloading allows expressions such as \texttt{a*b + a} to construct
the graph while computing their numerical results. Python integers and floats
are wrapped as \texttt{Value} objects when added or multiplied with a node.
Unsupported operand types return \texttt{NotImplemented}, allowing Python to
raise a \texttt{TypeError} when no compatible operation exists.

Each operation installs a local backward function on its output. This function
captures the input nodes and uses the output's gradient when it is eventually
called. Leaf nodes start with a backward function that does nothing.

\newpage
\section{Mathematical Derivations}
For an operation $z=f(a,b)$ and final scalar loss $L$, the chain rule gives
\begin{equation}
\frac{\partial L}{\partial a}
=\frac{\partial L}{\partial z}\frac{\partial z}{\partial a},
\qquad
\frac{\partial L}{\partial b}
=\frac{\partial L}{\partial z}\frac{\partial z}{\partial b}.
\end{equation}
Let $g_z=\partial L/\partial z$ denote the incoming gradient. The implementation
adds each contribution to the corresponding input gradient.
The formulas below apply where the real-valued expressions are defined.

\subsection{Arithmetic operations}
For addition, $z=a+b$, both local derivatives equal one:
\begin{equation}
g_a\mathrel{+}=g_z,\qquad g_b\mathrel{+}=g_z.
\end{equation}
For multiplication, $z=ab$, the product rule yields
\begin{equation}
g_a\mathrel{+}=b\,g_z,\qquad g_b\mathrel{+}=a\,g_z.
\end{equation}
For a constant exponent $p\in\mathbb{R}$, $z=a^p$ has derivative
\begin{equation}
g_a\mathrel{+}=p\,a^{p-1}g_z.
\end{equation}
The power method accepts an integer or floating-point exponent, not a
\texttt{Value} exponent. The case $p=0$ has zero derivative and is handled
explicitly to avoid evaluating $0^{-1}$ when the base is zero.

Negation, subtraction, and division reuse existing operations:
\begin{equation}
-a=(-1)a,\qquad a-b=a+(-b),\qquad \frac{a}{b}=a\,b^{-1}.
\end{equation}
Consequently, the derivative of division follows from the multiplication and
power rules. Division by a zero denominator raises \texttt{ZeroDivisionError}.
Reverse operators support expressions such as \texttt{2 + a}, \texttt{3*a},
\texttt{2 - a}, and \texttt{2/a}.

\subsection{Activation functions}
For $z=\tanh(a)$,
\begin{equation}
\frac{\mathrm{d}z}{\mathrm{d}a}=1-\tanh^2(a)=1-z^2,
\qquad g_a\mathrel{+}=(1-z^2)g_z.
\end{equation}
The forward pass uses \texttt{math.tanh}, avoiding an explicit ratio of
exponentials. For $z=\exp(a)$,
\begin{equation}
\frac{\mathrm{d}z}{\mathrm{d}a}=\exp(a)=z,
\qquad g_a\mathrel{+}=z\,g_z.
\end{equation}

\subsection{Why gradients accumulate}
If a node is used by multiple operations, its total derivative is the sum of
contributions from all outgoing paths. Replacing \texttt{+=} with \texttt{=}
would overwrite earlier contributions. For example, $z=a+a$ requires two
contributions of $g_z$, even though the input-node set contains $a$ only once.
The local addition function still updates $a$ twice.

\newpage
\section{Topological Sorting and Backpropagation}
The computational graph is a directed acyclic graph. During the forward pass,
inputs precede outputs; during backpropagation, each operation must receive all
downstream gradient contributions before propagating its own gradient.

\subsection{Depth-first post-order traversal}
The \texttt{\_get\_topo()} method uses depth-first search (DFS). A node is marked
as visited, its inputs are visited recursively, and the node is appended
\emph{after} all of its inputs. The visited set ensures that a shared node is
included only once.

\begin{lstlisting}
def build_topo(node):
    if node not in visited:
        visited.add(node)
        for child in node._prev:
            build_topo(child)
        topo.append(node)
\end{lstlisting}

The global backward pass seeds the output derivative with
$\partial L/\partial L=1$ and traverses the list in reverse:
\begin{lstlisting}
topo = self._get_topo()
self.grad = 1.0
for node in reversed(topo):
    node._backward()
\end{lstlisting}

The specific order of independent nodes may vary because \texttt{\_prev} is a
set, but all valid orders preserve the required dependencies. For $V$ nodes
and $E$ input links, graph traversal takes $O(V+E)$ time and $O(V)$ auxiliary
space, including the list, visited set, and recursion stack.

\subsection{Worked shared-node example}
Let $a=3$, $c=a+a$, and $d=ca$. Then
\begin{equation}
d=(a+a)a=2a^2=18,\qquad \frac{\mathrm{d}d}{\mathrm{d}a}=4a=12.
\end{equation}
Starting with $g_d=1$, multiplication contributes $a=3$ to $g_c$ and $c=6$
directly to $g_a$. Addition then contributes $g_c$ twice to $a$, giving
$g_a=6+3+3=12$. A valid topological list is $[a,c,d]$; its reverse executes
the multiplication before the addition.

\subsection{Gradient lifecycle}
The engine accumulates gradients instead of clearing them implicitly.
\texttt{reset\_grad()} clears one node, while network-level
\texttt{zero\_grad()} clears trainable parameters. The training loop constructs
a fresh graph each iteration. Reusing an already-backpropagated graph would
require handling intermediate gradients as well; clearing parameters alone
does not reset every node in an old graph. Parameter values must remain
unchanged between a forward calculation and its backward pass.

\section{Neural Network Design and Training}
\subsection{Neuron, layer, and MLP}
A neuron with $n$ inputs computes a weighted sum and applies $\tanh$:
\begin{equation}
z=\sum_{i=1}^{n}w_i x_i+b,\qquad \hat{y}=\tanh(z).
\end{equation}
Weights and bias are \texttt{Value} objects initialized independently using
\texttt{random.uniform(-1, 1)}. The neuron checks that the number of inputs
matches the number of weights. Using \texttt{Value} arithmetic automatically
connects all parameters to the graph; no separate neuron-level backward
method is needed.

A \texttt{Layer} contains several neurons sharing the same input vector. It
returns a list of outputs, or a single \texttt{Value} when it contains one
neuron, as required by the template. An \texttt{MLP} applies layers sequentially.
If a hidden layer returns a scalar, the MLP wraps it in a list before passing
it to the next layer. All neurons, including the output neuron, use $\tanh$.

The \texttt{parameters()} methods collect weights and biases into one flat
list. Their \texttt{zero\_grad()} methods call \texttt{reset\_grad()} on these
parameters. The network's learnable parameters persist across iterations.

\subsection{Architecture and loss}
The demonstration uses a $2\rightarrow4\rightarrow1$ MLP. Its parameter count is
\begin{equation}
4(2+1)+1(4+1)=12+5=17.
\end{equation}
For $N=4$ training examples, the mean squared error (MSE) is
\begin{equation}
L=\frac{1}{N}\sum_{k=1}^{N}(\hat{y}_k-y_k)^2,
\qquad
\frac{\partial L}{\partial\hat{y}_k}
=\frac{2}{N}(\hat{y}_k-y_k).
\end{equation}
Combining this with the output activation gives
\begin{equation}
\frac{\partial L}{\partial z_k}
=\frac{2}{N}(\hat{y}_k-y_k)(1-\hat{y}_k^2).
\end{equation}
For a neuron's weight, $\partial z_k/\partial w_i=x_{k,i}$, so gradients
accumulate over all examples and propagate through earlier layers.

\subsection{Gradient descent}
For each trainable parameter $\theta$, full-batch gradient descent applies
\begin{equation}
\theta\leftarrow\theta-\eta\frac{\partial L}{\partial\theta},\qquad\eta=0.1.
\end{equation}
Each iteration computes predictions and loss, clears old gradients, and runs
backpropagation. The parameter values are updated only after all current
gradients are available. Clearing gradients prevents contributions from
previous iterations from entering the current update.

\section{Validation, Discussion, and Limitations}
\subsection{Provided tests}
Running \texttt{python -m pytest -q} from the repository root gives
\textbf{12 passed}: nine engine tests and three network tests. Coverage includes
arithmetic, activations, type handling, shared-node gradients, the chain rule,
division by zero, parameter counts, and network backpropagation. These local
results are separate from the GitHub grading process.

\subsection{Independent numerical gradient check}
For an additional check, define
\begin{equation}
f(x)=\frac{\tanh(x^2+e^x)}{x+2}.
\end{equation}
At $x=0.4$, the engine's derivative was compared with the central difference
\begin{equation}
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h},\qquad h=10^{-6}.
\end{equation}
The engine produced $-0.030708460903$; the numerical approximation was
$-0.030708460885$. The absolute difference, approximately
$1.79\times10^{-11}$, supports the correctness of this composite derivative
at the tested point.

\subsection{Conceptual discussion}
\textbf{Why reverse-mode differentiation?} A scalar loss can depend on many
parameters. One reverse traversal propagates derivatives to every reachable
parameter, reusing the recorded forward graph.

\textbf{Why a nonlinear activation?} Composing affine layers without
nonlinearity still produces an affine function. XOR is not linearly
separable, so a nonlinear hidden representation is needed to fit its labels.

\textbf{Why both a visited set and gradient accumulation?} The visited set
ensures a node's backward function executes once. Accumulation sums the
contributions from every operation that uses that node. These solve distinct
problems in shared computation graphs.

\subsection{Scope and limitations}
The engine uses scalars rather than vectorized tensors. Recursive DFS is
limited by Python's recursion depth. Exponentials can overflow, and saturated
$\tanh$ units can have very small gradients. Higher-order differentiation,
differentiable exponents, and automatic old-graph gradient clearing are not
implemented.

\textbf{Conclusion.} Local derivative rules and reverse topological traversal
provide a reusable foundation for neurons and an MLP. The tests, numerical
check, and XOR experiment support the correctness of the implementation
within the demonstrated scope.
